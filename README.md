# Pasha Baby

Dedicated storefront for **پاشا بيبي — پاشا بەیبی — Pasha Baby**.

- Independent repository
- Independent Supabase project
- Public storefront in Arabic, Badini Kurdish and English
- Admin dashboard in Arabic and English
- Pasha Baby light retail theme

Customer contact/location/social details currently contain temporary placeholders and must be replaced before enabling live orders.
